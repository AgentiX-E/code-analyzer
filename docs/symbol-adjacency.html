Where the goldens we never credit were standing

33 goldens on core are credited by the competitor's arm and by nothing we emit at any budget. 26 of them sit on an identifier that a comment we already post names, and 26 of those 26 comments are inside their pull request's first 5. The deficit is not that we did not look; it is that the comment says something else.

A name is what the change writes, not what the sentence spells. The symbols counted here are the identifiers on the pull request's own added lines, minus keywords and minus anything inside a comment; reading the humans' sentences alone would count 27 of the same 33 instead of 26, because prose is mostly not code - Potential, Calling, particularly, capping. Both rows are drawn below, since a set that shrank is only interpretable beside the set it shrank from.

The rate that forbids aiming at it

Co-location is the board's base rate. 89 of the 125 goldens that are in neither set sit on a symbol our pool names, by the same rule and on the same pool - 71 % against 79 %. A device cannot select which comment to rewrite by asking whether it is near a golden we missed; it can only be pointed at every comment it posts.

What the count is worth, read against its own null

Each row sweeps the one parameter the rule has: how many pull requests' pools may name a token before it stops being a name - and the symbol set it counts is the golden sentence, restricted to names the pull request’s own added lines write. The bar is the count, the tick is the 500-permutation null's 95th percentile - the count the same geometry produces when the symbol sets are swapped between goldens. At the specificity this record uses (≤ 1) the observed count is 26 against a null of 1.37. The loose end of the sweep is why the count was never the finding: at any token every golden is adjacent, which is exactly what the rate above says.

The prize, and the arithmetic floor that is not it

Crediting each golden to the highest-scoring comment on its own pull request that names its symbol is the sentence being corrected and nothing else moving: no comment added, no rank changed, the budget unchanged at 227. Both readings of a rewrite - the credit added beside the one the comment already holds, or moved in place of it - land on the same point, which is why the record publishes both.

This is an upper bound and never a score. The judge never saw the corrected sentence. Its use is to refuse: if it were below 0.3735, no conditioning of the comments we already post could reach the bar.

How many corrections the bar actually costs

A conversion is not a credit - the protocol matches one finding to one golden - so the 26 conversions buy 13 credits, not 26. The curve is the plan in the order a verifier would apply it, most confident comment first; 17 of 26 corrections clear it, against an arithmetic floor of 10 that assumes a conversion is a credit.
